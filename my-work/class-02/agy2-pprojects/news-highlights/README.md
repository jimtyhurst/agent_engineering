# News Highlights

This work is based on the [News Highlights](https://codelabs.developers.google.com/building-with-google-antigravity#2) section of a Google Codelab, [Building with Google Antigravity](https://codelabs.developers.google.com/building-with-google-antigravity).

## Issues

The original prompt:
```
visit news.google.com and get me the highlights at the moment.
```
failed, due to permissions problems opening a browser.

However, this prompt:
```
Fetch top news headlines using web search and HTTP request instead of the browser.
```
worked okay, because it did not require opening a browser.
